# Screenshots

Place the images referenced by the README in this directory.

| File | Page | Must show |
|---|---|---|
| `01-agents.png` | Agents | List with status, visibility and mount summary |
| `02-chat.png` | Chat | Streaming answer, knowledge citation panel, tool timeline |
| `03-skills.png` | Skills | Skill library with rollout percentage and targeted users |
| `04-knowledge.png` | Knowledge | Knowledge base detail with documents and chunk counts |

## Capture checklist

- 1440 × 900 viewport, 100% zoom, light theme, current main build.
- Use a **demo dataset** created for the screenshots: no real employees, departments, customer
  names, hostnames, model keys or conversation content.
- Redact or avoid: model keys, MCP secrets, internal URLs, email addresses, phone numbers,
  account names that map to real people.
- Keep the browser chrome out of the image; crop to the app viewport.
- Save as PNG, target < 500 KB each, and check that no request in the Network panel leaks a token
  into the visible URL bar.
- After adding a file here, embed it in both `README.md` and `README.zh-CN.md` with alt text.
